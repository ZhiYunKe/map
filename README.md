# 沪上漫游 · Shanghai Pocket Atlas

面向 2026 年 10 月 2 日晚至 10 月 5 日的上海旅行交互式 3D 页面。

## 打开

直接双击 `index.html`，推荐 Chrome 或 Edge。所有运行资源随项目提供，3D、行程与清单离线可用；地图和官方来源链接需联网。

无需安装 Node.js、npm，无需账号和 API 密钥。若浏览器不支持 WebGL，行程与预约清单仍然可用。

## 操作

- 拖动沙盘旋转，滚轮缩放；Shift＋拖动或鼠标右键拖动平移。手机双指缩放和平移。
- 点击建筑标签或左侧景点，查看交通、候车和排队时间。
- 切换日期显示当日路线及完整时间线。
- 点击沙盘下方播放键开始“逐站漫游”，每5秒沿当天路线前往下一站；也可手动前后切站、暂停。切换日期或打开详情时停止或暂停播放。
- 日景／夜景、俯视／全景、标签开关、全屏查看、明信片图片保存。
- 手机底部切换“探索沙盘 / 每日行程 / 出发清单”，点击景点直接打开详情。
- 出发清单共4项（含首班地铁复核），在当前浏览器本地保存进度；更换浏览器、清理站点数据后不保留。
- “地图中查看”打开高德搜索，“信息来源”可访问对应官方页面。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面入口与语义结构 |
| `styles.css` | 响应式布局、日夜主题 |
| `app.js` | 日期、详情、清单、图片保存交互 |
| `scene.js` | Three.js 场景、模型、相机和拾取 |
| `trip-data.js` | 行程、地点、票务、来源信息 |
| `vendor/three.min.js` | 本地 Three.js 0.160.1 运行库 |
| `vendor/THREE-LICENSE.txt` | Three.js MIT 许可证 |

技术选择：Three.js WebGL + 原生 JavaScript / CSS。该页面无需服务端和构建工具，适合本地直接使用、后续作为静态网页部署。地标采用程序化几何建模，不依赖远程三维资产。

## 数据边界

本项目是非等比例的艺术化行程沙盘，不是测绘地图。建筑高度、街区、黄浦江、位置间距及路线均为视觉示意，线路连线不表示实际轨道走向。请用正规地图导航。

页面中的乘车、候车、排队时间是规划预留，没有接入实时公交、票务或航班服务。预约和票务规则应以出行时官方公告为准，值机和登机截止时间按航空公司要求。交大13:10为计划时间，不代表预约已成功。上海中心计划入场调整为16:25，若已购票须核对场次与退改规则；北外滩夜间开放及临时管控以现场公告为准。

不收集个人数据、不发送分析请求。勾选清单并不实际预约或购票。
